# Rules for qemqemqem/articlesong

Keenan's rules for this repo (see the "Repo rules: RULES.md" section of Keenan's global CLAUDE.md).
Where this file says nothing, the usual rules apply.

## Shipping to limitcycle.ai includes the guide
Article Song has a guide on limitcycle.ai at `/docs/articlesong/`, kept in
qemqemqem/limitcyclelabs at `site/content/docs/articlesong.md`.

- When a user-visible change goes live on limitcycle.ai, update the guide to match, in the
  qemqemqem/limitcyclelabs PR that ships it or in a hub PR opened alongside. Check it against
  what is live. If nothing a user would notice changed, say so in the PR.
- A new project from this repo that becomes public on limitcycle.ai gets a guide in the PR that
  makes it public.
- Guides describe what is live, not what is on a branch.
